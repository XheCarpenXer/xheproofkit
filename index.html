Counterfactual Analysis. Each branch point in the execution trace has a set of alternative paths that could have been taken. These alternatives are cryptographically anchored to the actual stateHash at that decision point — proving what could have happened and that the system only follows one path. Useful for regulatory audit ("what would happen if creditScore was 650?").
⎇ Alternative Path Explorer
Merkle Proof Certificate. Constructs a SHA-256 Merkle tree over the execution trace hashes. The Merkle root commits to the entire execution in O(log n) space. The final proof package includes: wfHash, irHash, inputHash, effectHash, outputHash, choiceHash, traceHash, merkleRoot — all combined and signed with your ECDSA key. Any trace tampering invalidates the proof.
